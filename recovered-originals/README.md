# Recovered originals

Three modules that existed in no other repository. They came from the unmerged `claude/recovered-originals` branch of the Data_files repository, which is archived, and are copied here unchanged so that retiring it loses nothing.

| File | Bytes | Git blob |
|---|---|---|

| `solvar_stability_governance_source.recovered.py` | 38,043 | `4a98a18` |
| `eddp-pipeline-core-simple.recovered.py` | 1,177 | `6f41500` |

The flattened versions of the first two are in `specimens/pairs/`. These are the recovered, unflattened forms.

This directory sits outside `specimens/` on purpose. `verify_manifest.py` checks the SHA-256 of every file under `specimens/`, and these files are not catalogued specimens.
