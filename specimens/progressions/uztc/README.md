— Provenance, Alignment Filter, Defense Shield, Isolation Protocol,
Synthesis, Hygiene Protocol, Command & Control — across three revisions
(`uztc-construct-v1.0/1.1/1.2`). None of the three execute meaningfully
(syntax error or silent no-op); this is conceptual/architectural material,
not working code. See `PROVENANCE.md` for the full source writeup.
